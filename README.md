# Project 3: Spots

### Overview

- Intro to figma
- inputing images
- Images layout

**Intro**

This project is made so all the elements are displayed correctly on popular screen sizes. This was also taking a look at using figma as a tool to help design an inputting images social platform.

**inputing images**

This begining of the project takes a look at uploading a picture and leaving a descrition for a user to share to a social subpace. Things to look out for is how the text is to wrap or not to be fully seen if it exceeds the space that is allowed for the text.

**Images layout**

I have implemented a grid layout for the pictures that will be equal size to each other, also having the dynamic change to the grid when reaching different viewing sizes from different devices being used. This is to ensure use on various platforms. Have a look [here]https://casapapas16.github.io/se_project_spots/
